# ExamGhost Keyword Map (SERP-evidence based)

Research date: 2026-11-19. US WebSearch results, about 20 queries, plus one WebFetch to check page type.

## How to read this

- **No volume or difficulty data.** No search-volume tool was available, so no volumes or KD scores were invented. Priority (High / Medium / Low) is a qualitative call based on three things:
  - how many ranking results target the exact phrase
  - how clear the intent is
  - what kind of page ranks
- **Result types.** The results are mostly Chrome Web Store listings, extension directories (chromeboard, extscope, neura.market, topai.tools), vendor landing pages, and vendor-written "best of" listicles. Independent editorial reviews are rare.
- **Length limits.** Titles are <= 60 characters and meta descriptions <= 155. I counted by hand, so run a length lint before shipping.
- **Missing facts.** `[needs owner fact]` marks a fact only the ExamGhost team can supply.
- **Integrity framing.** Copy should present ExamGhost as a homework, practice, and study helper with explanations. It should not be positioned for proctored or graded-exam use.
